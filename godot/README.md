# Western Rush RP Mobile — KLD

Godot 4 project for an original mobile roleplay game inspired by Kaliningrad.

## Open the project
1. Install Godot 4.3 or newer.
2. In Godot Project Manager, choose Import.
3. Select this folder's `project.godot`.
4. Press Play.

## Prototype 0.1
- Procedural 3D city blockout.
- Pregolya river and three bridges.
- North, central, east, west, south and industrial districts.
- Placeholder landmarks: Victory Square, Cathedral, Fish Village, bus station, airport, hospital and police.
- Basic player capsule with gravity and collision.
- Touch D-pad and sprint button for Android, plus WASD/arrow keyboard input.
- Lit 3D scene with ambient light and directional sunlight.

This is an early graybox map, not a finished replica and not yet an Android APK. Models, roads, terrain, touch controls, optimization and Android export remain to be developed.
